## Original postcard illustration

`public/assets/palmetto-postcard.png` was generated for this project with OpenAI image generation. No Rockstar artwork, logos, game audio or extracted game assets are included.

Bold shapes, tactile grain, elevated cinematic perspective, warm cream, ochre, coral and teal shadows. Artwork only, no text, logos, watermark, UI or border.

Gameplay map and miniature city are original Canvas and Three.js geometry. Sound effects are synthesized with Web Audio.

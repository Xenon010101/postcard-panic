# Skill and tool reference

This file maps available workflows; it is not an installed Codex skill and does not override user or system instructions.

| Workflow | When to use | Project application |
| --- | --- | --- |
| Sites building / hosting | Preview, build, and public deployment | Preserve the explicitly selected Vite stack; static output is `dist`. Public access is a contest requirement. |
| Imagegen | Original illustrative artwork | Create one coastal postcard illustration; keep functional map geometry in code. Save final assets in `public/assets` and document their provenance. |
| Computer/browser use | Requested integration and interaction verification | Test real editor save/cancel, route validation, replay, import/export, and responsive views. |
| GitHub tools / CLI | Public source delivery | Use existing authenticated access; never store credentials in the repository. |

Read each installed skill's current SKILL.md before first use. Do not silently substitute an imitation image editor. Prefer documented Unlayer interfaces and official library documentation. Use generated art for decorative imagery; the deterministic road diagram and Three.js gameplay geometry remain code-native.

Asset-only delegation is permitted by the Sites image workflow. Product code stays in the owning task unless the user explicitly requests further delegation.
